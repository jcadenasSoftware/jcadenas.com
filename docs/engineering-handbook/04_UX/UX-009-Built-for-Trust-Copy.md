# UX-009 — Built for Trust Copy

**Estado:** Aprobado

**Versión:** 1.0

**Fecha:** 2026-08-05

**Proyecto:** Xpendz

---

# 1. Objetivo

Definir el contenido textual de la sección **Construido para inspirar confianza**.

Esta sección tiene como propósito reforzar la confianza del visitante antes del llamado final a la acción.

No busca vender más funcionalidades.

Busca explicar los principios sobre los que fue construido Xpendz.

---

# 2. Título principal

## Construido para inspirar confianza.

---

# 3. Introducción

Xpendz fue diseñado para ayudarte a comprender mejor tus finanzas mediante una experiencia clara, sencilla y organizada.

Cada decisión de diseño tiene un propósito: facilitar el control de tu dinero.

---

# 4. Principio 1

## Claridad

Toda tu información financiera se presenta de forma sencilla para que siempre sepas dónde estás y puedas tomar mejores decisiones.

---

# 5. Principio 2

## Simplicidad

Administrar tu dinero no debería sentirse como trabajar en una hoja de cálculo.

Xpendz elimina la complejidad para que puedas concentrarte en lo importante.

---

# 6. Principio 3

## Organización

Cuentas, categorías, presupuestos y metas trabajan juntos para ayudarte a mantener el control sin esfuerzo.

---

# 7. Principio 4

## Evolución

Xpendz es un proyecto en constante crecimiento.

Cada nueva versión busca simplificar la experiencia y aportar más valor a sus usuarios.

---

# 8. Cierre

La confianza no se construye con promesas.

Se construye con decisiones de diseño pensadas para ayudarte a administrar mejor tu dinero.

---

# 9. Tono

Toda la comunicación deberá transmitir:

- claridad;
- cercanía;
- profesionalismo;
- honestidad;
- confianza.

No se utilizarán frases exageradas ni afirmaciones imposibles de verificar.

# 11. Documento vivo

Los textos podrán evolucionar conforme el producto incorpore nuevas capacidades.

Sin embargo, la filosofía de esta sección deberá mantenerse: generar confianza mediante hechos y decisiones de diseño, no mediante mensajes promocionales.
